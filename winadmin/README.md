## 📋 نظرة عامة

WinAdmin هو تطبيق سطح مكتب متكامل مبني بـ Python لتشخيص وحل مشاكل أنظمة Windows. يوفر واجهة رسومية احترافية مع مراقبة فورية للموارد، إدارة العمليات والخدمات، فحص الأمان، وإنشاء التقارير.

## ✨ الميزات

| الميزة | الوصف |
|---|---|
| 📊 لوحة التحكم | عرض فوري لـ CPU, RAM, Disk, Network مع مقاييس دائرية |
| 📈 مراقبة الموارد | رسوم بيانية مباشرة مع تفاصيل كل مورد |
| ⚙ إدارة العمليات | عرض، تصفية، إيقاف العمليات الجارية |
| 💾 إدارة التخزين | مجلدات كبيرة، تنظيف مؤقت، حجم التطبيقات |
| 🔧 إدارة الخدمات | تشغيل/إيقاف، تغيير نوع البدء |
| 🛡 الأمان والصحة | Defender، تحديثات، أخطاء النظام |
| 📋 السجلات والتقارير | تقارير يومية/أسبوعية، تصدير CSV/JSON |
| ⚙ الإعدادات | عتبات تنبيهات، بريد إلكتروني، أجهزة بعيدة، مظهر |

## � المتطلبات التقنية

- **Python 3.9+**
- **نظام التشغيل**: Windows 10/11 (يعمل جزئياً على Linux)
- **الصلاحيات**: يُنصح بالتشغيل كم مسؤول (Run as Administrator)

## 📦 التثبيت خطوة بخطوة

### 1. استنساخ المشروع
```bash
git clone https://github.com/your-username/winadmin.git
cd winadmin
```

أو فك ضغط الملف المُنزّل:
```bash
unzip winadmin.zip
cd winadmin
```

### 2. إنشاء بيئة افتراضية (مستحسن)
```bash
python -m venv venv

# على Windows:
venv\Scripts\activate

# على Linux/macOS:
source venv/bin/activate
```

### 3. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

> **ملاحظة لمستخدمي Windows**: مكتبة `wmi` تحتاج إلى `pywin32`:
> ```bash
> pip install pywin32
> ```

### 4. تشغيل التطبيق
```bash
python main.py
```

> **ملاحظة**: للتشغيل بصلاحيات كاملة على Windows:
> انقر بزر الفأرة الأيمن على CMD → **Run as Administrator** → ثم شغّل التطبيق

## 🎮 كيفية الاستخدام

### لوحة التحكم
- تعرض ملخصاً فورياً لحالة النظام
- مقاييس دائرية لـ CPU, RAM, Disk, Network
- تنبيهات تلقائية عند تجاوز العتبات
- آخر الأخطاء من سجل النظام

### مراقبة الموارد
- تبويبات تفصيلية: CPU, RAM, Disk, Network
- رسوم بيانية تُحدّث مباشرة كل 1.5 ثانية
- تفاصيل كل نواة معالج بشكل منفصل

### إدارة العمليات
- ابحث عن أي عملية بالاسم أو PID
- رتّب حسب استهلاك CPU أو RAM
- أوقف أي عملية بزر **⛔ إيقاف العملية**
- قائمة سياق بزر الفأرة الأيمن

### إدارة التخزين
- **📂 البحث عن مجلدات كبيرة**: يمسح القرص ويجد المجلدات التي تتجاوز 500 MB
- **🧹 تنظيف الملفات المؤقتة**: يحذف ملفات Temp وCache
- **📦 حجم التطبيقات**: يعرض التطبيقات المثبتة وحجمها
- توصيات ذكية لتحرير المساحة

### إدارة الخدمات
- عرض جميع خدمات النظام مع حالتها
- تشغيل/إيقاف أي خدمة
- تغيير نوع البدء (تلقائي/يدوي/معطّل) من قائمة السياق
- فلترة حسب الحالة (Running/Stopped)

### الأمان والصحة
- فحص حالة Windows Defender
- عرض التحديثات المعلقة
- قراءة أخطاء Event Viewer
- عرض الخدمات الحرجة وحالتها
- عرض المستخدمين النشطين والجلسات

### السجلات والتقارير
- سجل أداء يُسجّل تلقائياً كل ثانيتين
- سجل أخطاء النظام
- إنشاء تقرير يومي أو أسبوعي
- تصدير البيانات كـ CSV أو JSON

### الإعدادات
- تعيين عتبات التنبيهات (CPU, RAM, Disk)
- إعداد تنبيهات البريد الإلكتروني (SMTP)
- إدارة الأجهزة البعيدة
- التبديل بين المظهر المظلم والفاتح
- تحديد مسار حفظ السجلات
- تنظيف البيانات القديمة

## 🔧 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| لا يعمل التطبيق | تأكد من Python 3.9+ و`tesseract` المكتبات مثبتة |
| خطأ `wmi` | شغّل `pip install pywin32 wmi` على Windows |
| صلاحيات مرفوضة | شغّل التطبيق كم مسؤول (Run as Administrator) |
| واجهة غير واضحة | غيّر المظهر من الإعدادات → المظهر والسجلات |
| بطء في التحديث | أغلق صفحات أخرى لتقليل الحمل |
